# Arxiv (tarixiy fayllar)

Bu papkada 2026-yil oktyabrigacha repo ildizida turgan eski hujjatlar va bir martalik
tuzatish/tekshirish skriptlari saqlanadi.

**Diqqat:**

- Ular **eskirgan**: ko'plari oldingi server (port, domen, ikki alohida repo) uchun yozilgan.
- Ba'zilari xavfli edi (masalan, foydalanuvchilarni o'chirib, ochiq parol bilan qayta yaratish).
  Productionda **ishga tushirmang**.
- Ichidagi parollar va kalitlar `<ochirilgan-parol>` bilan almashtirilgan. Asl qiymatlar git
  tarixida qolgan — ular almashtirilgan bo'lishi kerak (qarang: `docs/OPERATIONS.md`).
