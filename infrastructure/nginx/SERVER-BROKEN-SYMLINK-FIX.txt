CDCGroupNew / boshqa server — HTTPS tuzatish (symlink xato)
============================================================

SABAB
-----
1) `sudo ln -sf ...` bilan symlink yaratilgan, lekin `sites-available` dagi manba fayl
   YO'Q (cp avval xato bergan). Natija: sindilgan symlink → nginx emergency.
2) `/phonix/repo` yo'li serverda mavjud emas — loyiha boshqa papkada.

DARHOL (nginx va certbotni tiklash)
-----------------------------------
1) Sindilgan symlink ni O'CHIRING (nginx qayta ishlaydi):

   sudo rm -f /etc/nginx/sites-enabled/phoenix-ilmiyfaoliyat-frontend

   Agar sites-available da ham bo'sh/yaroqsiz fayl qolgan bo'lsa:

   sudo rm -f /etc/nginx/sites-available/phoenix-ilmiyfaoliyat-frontend

2) Tekshirish:

   sudo nginx -t && sudo systemctl reload nginx

   Ogohlantirish `listen ... http2 deprecated` — boshqa sayt (00-fjsti-ziyrak.conf)
   bilan bog'liq; emergency emas.

SERTIFIKAT (Let's Encrypt yo'q bo'lsa)
--------------------------------------
Oldin SSL blokli nginx konfigni qo'yish mumkin EMAS — fullchain.pem yo'q bo'lsa
`nginx -t` yana xato beradi.

Variant A — qisqa to'xtatish (oddiy):

   sudo systemctl stop nginx
   sudo certbot certonly --standalone -d ilmiyfaoliyat.uz -d www.ilmiyfaoliyat.uz
   sudo systemctl start nginx

Variant B — nginx ishlayotganda webroot (keyin qo'shimcha HTTP blok kerak).

FRONTEND KONFIGNI YARATISH (repo yo'q — qo'lda)
-----------------------------------------------
Loyiha yo'lini aniqlang (masalan frontend build qayerda):

   sudo find / -name "dist" -path "*/frontend/dist" 2>/dev/null | head -5

`root` direktoriyasini konfigda shu yo'lga moslang (masalan `/phonix/frontend/dist`
yoki `/var/www/ilmiyfaoliyat/dist`).

Keyin:

   sudo nano /etc/nginx/sites-available/phoenix-ilmiyfaoliyat-frontend

Quyidagi mazmunni qo'ying (ROOT va ssl yo'llarini tekshiring). Fayl loyihada:
`infrastructure/nginx/phoenix-ilmiyfaoliyat-frontend.conf`

   sudo ln -sf /etc/nginx/sites-available/phoenix-ilmiyfaoliyat-frontend \
               /etc/nginx/sites-enabled/phoenix-ilmiyfaoliyat-frontend

   sudo nginx -t && sudo systemctl reload nginx

Agar `options-ssl-nginx.conf` yo'q bo'lsa:

   sudo apt install -y python3-certbot-nginx

Agar `ssl-dhparams.pem` yo'q bo'lsa:

   sudo openssl dhparam -out /etc/letsencrypt/ssl-dhparams.pem 2048

CERTBOT --nginx (konfig tayyor va sertifikat mavjud bo'lgach)
-------------------------------------------------------------
   sudo certbot --nginx -d ilmiyfaoliyat.uz -d www.ilmiyfaoliyat.uz

ESLATMA
-------
- Keyingi safar `cp` dan OLDIN manba fayl borligini tekshiring:
  `ls -la /yo'l/phoenix-ilmiyfaoliyat-frontend.conf`
- Symlink faqat haqiqiy fayl `sites-available` da bo'lgandan keyin.


=== APPENDIX: to'liq nginx matni (nano ga nusxa) ===
`root` qatorini serverdagi frontend `dist` yo'liga o'zgartiring.

server {
    listen 80;
    listen [::]:80;
    server_name ilmiyfaoliyat.uz www.ilmiyfaoliyat.uz;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    listen [::]:443 ssl;
    http2 on;
    server_name ilmiyfaoliyat.uz www.ilmiyfaoliyat.uz;

    ssl_certificate /etc/letsencrypt/live/ilmiyfaoliyat.uz/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/ilmiyfaoliyat.uz/privkey.pem;
    include /etc/letsencrypt/options-ssl-nginx.conf;
    ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;

    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;

    root /phonix/frontend/dist;
    index index.html;

    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;
    gzip_min_length 1000;

    location / {
        try_files $uri $uri/ /index.html;
        add_header Access-Control-Allow-Origin *;
        add_header Access-Control-Allow-Methods 'GET, OPTIONS';
    }

    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot|otf|mp4|webm|ogg|ogv|pdf|doc|docx)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
        access_log off;
    }

    location ~* \.html$ {
        add_header X-Frame-Options "SAMEORIGIN" always;
        add_header X-Content-Type-Options "nosniff" always;
        add_header X-XSS-Protection "1; mode=block" always;
    }

    location ~ /\. {
        deny all;
        access_log off;
        log_not_found off;
    }
}
